### 3. VLM Document Extraction Specification

The VLM extracts raw semantic observations, layout structures, and evidence anchors without computing compliance decisions.

```
Extraction Meta-Schema:
- Field Value: <extracted_primitive_or_object>
- Confidence Score: Float (0.00 to 1.00)
- Evidence Anchor: { "file_name": String, "page_number": Integer, "bounding_box": [ymin, xmin, ymax, xmax], "text_quote": String }
- Extraction Status: Enum("directly_visible", "derived_verbatim", "ambiguous", "not_found", "illegible")

```

### 4. Deterministic Backend Validation Specification

The deterministic engine consumes structured VLM observations and evaluates mathematical, relational, and temporal constraints.

#### 4.1 Rule Set: Eligibility, Names, and Financial Viability

* **RULE-GEN-01: Prohibited Word & Institutional Acronym Verification**
* *APH Source Provision:* Chapter I, Clause 1.5.4, p. 5.


* *Applicability:* New Institution, Institution Name Change.
* *Inputs:* Application Record `proposed_institution_name`, `promoter_category`.
* *Operation:* Regex test against prohibited acronyms `\b(IIT|IIM|IISc|NIT|IISER|IIIT|IIEST|AICTE|UGC|MoE|GoI)\b` and protected words `\b(Government|India|Indian|National|All India|Commission)\b`.
* *Expected Result:* If `promoter_category != "Government"` and match found, evaluate `FAIL (PROHIBITED_NAME_USED)`.
* *Traceability & Finding:* Output the exact string and token matched, citing Clause 1.5.4.




* **RULE-FIN-01: Liquid Operational Fund Adequacy**
* *APH Source Provision:* Chapter I, Clause 1.5.3, Table 1.2, p. 5.


* *Applicability:* New Institution.
* *Inputs:* VLM extraction from DOC-10 (`balance_amount_in_inr`), Application Record `proposed_programmes`.
* *Operation:* Lookup threshold $T$ from Table 1.2:



$$\text{Threshold } T = \begin{cases} ₹100\text{ Lakh} & \text{if Engineering \& Technology} \\ ₹50\text{ Lakh} & \text{for any other Technical Programme} \end{cases}$$



Evaluate condition: $\sum \text{balance\_amount\_in\_inr} \ge T$.


* *Expected Result:* Pass if total unencumbered bank funds meet or exceed $T$; else flag `FAIL (INSUFFICIENT_OPERATIONAL_FUNDS)`.


* *Exceptions:* Government or State University applicants require proof of minimum budget allocation of ₹100 Lakh in lieu of Bank FDRs.





#### 4.2 Rule Set: Land Title, Tenancy, and Spatial Layout

* **RULE-LND-01: Land Leasehold Duration & Live Lease Balance**
* *APH Source Provision:* Chapter I, Clause 1.5.1(a); Chapter II, Clause 2.1(e); Chapter VI, Clause 6.17(a, b); Annexure 1.1, p. 4, 12, 56, 77.


* *Applicability:* New Institution, EoA (if leased land).
* *Inputs:* VLM extraction from DOC-03 (`deed_type`, `lease_tenure_years`, `registration_date`, `lease_expiry_date`), DOC-04 (`irrevocable_clause_present`), Application Record `application_submission_date`, `max_course_duration_years`.
* *Operation:*
1. If `deed_type == "Private Lease"` or `"Govt Lease"`: Verify $\text{lease\_tenure\_years} \ge 30$.


2. Compute remaining live lease: $\Delta T_{\text{live}} = \text{lease\_expiry\_date} - \text{application\_submission\_date}$.
3. For New Institution: Assert $\Delta T_{\text{live}} \ge 5\text{ years}$.


4. For EoA: Assert $\Delta T_{\text{live}} > \text{max\_course\_duration\_years}$; if false, check if extended lease document for $\ge 30\text{ years}$ is submitted.




* *Expected Result:* Pass if tenure satisfies 30 years and live duration covers required thresholds; else flag `FAIL (INVALID_OR_EXPIRING_LEASE)`.




* **RULE-LND-02: Spatial Plot Discontinuity & Radial Distance Check**
* *APH Source Provision:* Chapter VI, Clause 6.17(d); Annexure 3.1(g, h), p. 56, 86.


* *Applicability:* New Institution.
* *Inputs:* VLM extraction from DOC-03 and DOC-14 (`land_parcels`, coordinates), DOC-06 (`carpet_area_summary`).
* *Operation:*
1. Count total distinct land parcels: $N_{\text{plots}} \le 3$.


2. If $N_{\text{plots}} > 1$: Compute pairwise geodesic distance $D(i, j)$ between centroid of plot $i$ and plot $j$. Assert $\max(D(i, j)) \le 2.0\text{ km}$.


3. Check functional allocation: 100% of Academic, Instructional, Administrative, and Amenities built-up area must reside entirely on Plot 1. Plots 2 and 3 can only be used for sports, hostels, or staff quarters.




* *Expected Result:* Pass if parcels $\le 3$, distance $\le 2\text{ km}$, and no academic rooms are assigned to secondary plots.





#### 4.3 Rule Set: Structural, Occupancy, and Fire Safety Validity

* **RULE-SAF-01: Fire Safety Certificate Operational Currency**
* *APH Source Provision:* Chapter VI, Clause 6.17(i); Annexure 1.1(v); Annexure 2.1(v), p. 56, 77, 81.


* *Applicability:* All Paths (New, EoA, Expansion).
* *Inputs:* VLM extraction from DOC-09 (`expiry_date`, `issue_date`, `covered_building_blocks`, `institution_name_referenced`), Application Record `processing_academic_year_end_date`, `institution_name`.
* *Operation:*
1. Verify string similarity: $\text{Levenstein}(\text{institution\_name\_referenced}, \text{institution\_name}) \ge 0.90$.
2. Temporal check: $\text{expiry\_date} \ge \text{processing\_academic\_year\_end_date}$.
3. If `expiry_date == null`, flag status `EXTRACTION_UNCERTAIN (EXPIRY_NOT_STATED)`.


* *Expected Result:* Pass if active across processing year; flag `FAIL (FIRE_SAFETY_EXPIRED)` if date is in the past.




* **RULE-SAF-02: Mandatory Structural Stability Validation for Aged Buildings**
* *APH Source Provision:* Chapter VI, Clause 6.17(h); Annexure 2.1(iv); Annexure 3.1(e), p. 56, 81, 86.


* *Applicability:* EoA, Expansion (where existing buildings are used).
* *Inputs:* VLM extraction from DOC-07 (`issue_date`), DOC-08 (`issue_date`, `structural_engineer_qualification`), Application Record `current_date`.
* *Operation:*
1. Calculate building age: $\text{Age}_{\text{bldg}} = \text{current\_date} - \text{DOC-07.issue\_date}$.
2. If $\text{Age}_{\text{bldg}} > 30\text{ years}$: DOC-08 is mandatory.


3. If mandatory: Check $(\text{current\_date} - \text{DOC-08.issue\_date}) \le 5\text{ years}$.


4. Check qualification: DOC-08 must confirm issuing engineer holds M.Tech / Master's in Structural Engineering.




* *Expected Result:* If $> 30$ yrs and DOC-08 missing or older than 5 yrs, evaluate `FAIL (STRUCTURAL_STABILITY_EXPIRED_OR_ABSENT)`.





#### 4.4 Rule Set: Infrastructure & Space Sizing Calculations

* **RULE-INF-01: Instructional Area Classroom Dimension & Capacity Compliance**
* *APH Source Provision:* Annexure 3.2.1, p. 87–90.
* *Applicability:* New Institution, Expansion.
* *Inputs:* VLM extraction from DOC-06 (`room_schedule_table`), Application Record `applied_courses`, `divisions_per_course`, `course_duration_years`.
* *Operation (for Engineering & Technology UG/Diploma):*
1. Determine required classroom count:

$$N_{\text{classrooms\_required}} = \sum_{\text{courses}} \left(\text{divisions\_per\_year} \times \text{duration\_years} \times 0.5\right)$$





2. Determine unit classroom area threshold:

$$A_{\text{unit\_min}} = \begin{cases} 66\text{ m}^2 & \text{if division size } = 60 \\ 33\text{ m}^2 & \text{if division size } = 30 \end{cases}$$





3. Filter `room_schedule_table` for `room_designation == "Classroom"`.
4. Count qualified rooms: $N_{\text{valid}} = \text{Count}(\text{rooms where } \text{carpet\_area\_sqm} \ge A_{\text{unit\_min}})$.
5. Evaluate tutorial rooms: Count rooms where `room_designation == "Tutorial Room"` and `carpet_area_sqm` $\ge 33\text{ m}^2$. Assert $N_{\text{tutorial}} \ge 0.25 \times N_{\text{classrooms\_required}}$.




* *Expected Result:* Pass if $N_{\text{valid}} \ge N_{\text{classrooms\_required}}$ and tutorial ratio $\ge 25\%$; else flag deficiency count.




* **RULE-INF-02: Laboratory Provisioning by Curriculum & Approved Divisions**
* *APH Source Provision:* Annexure 3.2.1(A), p. 87–88.
* *Applicability:* New Institution, Expansion.
* *Inputs:* VLM extraction from DOC-06 (`room_schedule_table`), Application Record `total_applied_intake`, `applied_courses`.
* *Operation:*
1. First-Year Lab check: If total intake $\le 600$, require 4 first-year labs ($\ge 66\text{ m}^2$ each, including 2 for Basic Sciences).


2. Higher-Year Labs: For each course, require $2 \times (\text{duration} - 1)$ laboratories ($\ge 66\text{ m}^2$ each) for up to 180 intake. If divisions per course $> 3$, scale labs pro-rata.


3. "X" Category Specialized Labs: If applied branch is in $\{\text{Mechanical, Production, Civil, Electrical, Chemical, Textile, Marine, Aeronautical}\}$, check for an additional Workshop/Lab of $\ge 200\text{ m}^2$ (for UG) or $\ge 150\text{ m}^2$ (for Diploma).


* *Expected Result:* Pass if all required laboratory designations and minimum carpet areas exist in the schedule.


* **RULE-INF-03: Administrative and Amenities Macro Area Compliance**
* *APH Source Provision:* Annexure 3.3, 3.4, p. 90–91.
* *Applicability:* New Institution, Expansion.
* *Inputs:* VLM extraction from DOC-06 (`carpet_area_summary`), Application Record `total_intake`.
* *Operation:*
1. If $\text{total\_intake} \le 300$: Assert $\text{administrative\_area\_sqm} \ge 750\text{ m}^2$ and $\text{amenities\_area\_sqm} \ge 500\text{ m}^2$.


2. Circulation check: Assert $\text{circulation\_area\_sqm} \approx 0.25 \times (\text{instructional} + \text{administrative} + \text{amenities})$.




* *Expected Result:* Pass if macro carpet totals meet statutory baselines.





#### 4.5 Rule Set: Faculty Sizing & Academic Composition

* **RULE-FAC-01: Faculty-to-Student Ratio (FSR) & Cadre Distribution**
* *APH Source Provision:* Chapter VI, Clause 6.14; Annexure 5.1, 5.2, 5.3, p. 55–56, 95–96.
* *Applicability:* EoA, Expansion.
* *Inputs:* VLM extraction from DOC-15 (`faculty_records`), Application Record `enrolled_students_all_years` ($S$).
* *Operation (for Engineering & Technology UG):*
1. Prescribed ratio: $FSR = 1:20$. Target faculty $F_{\text{target}} = \frac{S}{20}$.


2. Check Principal: 1 qualified Principal required ($A = 1$).


3. Cadre Ratio Check: Distribution factor $R = (1 + 2 + 6) = 9$.



$$\text{Professors Required } (B) = \frac{S}{20 \times 9} \times 1$$





$$\text{Associate Professors Required } (C) = \frac{S}{20 \times 9} \times 2$$





$$\text{Assistant Professors Required } (D) = \frac{S}{20 \times 9} \times 6$$





4. Adjunct/Practice Faculty Cap: Verify that $\text{Count}(\text{Adjunct}) + \text{Count}(\text{Prof of Practice}) \le 0.15 \times F_{\text{target}}$.




* *Expected Result:* Pass if total active regular faculty meets $F_{\text{target}}$ and cadre tiers are fulfilled.




* **RULE-FAC-02: Regular Salary Payment via Electronic Clearing System (ECS)**
* *APH Source Provision:* Chapter VI, Clause 6.14(a), p. 55.


* *Applicability:* EoA.
* *Inputs:* VLM extraction from DOC-15 (`monthly_salary_disbursement_mode`).
* *Operation:* For all listed regular faculty members, verify $\text{monthly\_salary\_disbursement\_mode} == \text{"ECS/Bank Transfer"}$.


* *Expected Result:* If cash or non-bank disbursements are extracted, flag `FAIL (UNAUTHORIZED_SALARY_MODE)`.





#### 4.6 Rule Set: Change & Expansion Discipline Rules

* **RULE-EXP-01: Baseline Core Branch Prerequisite for Expansion**
* *APH Source Provision:* Chapter II, Clause 2.6(c), p. 16.


* *Applicability:* Expansion in Engineering & Technology (Diploma, UG, PG).
* *Inputs:* Application Record `existing_approved_courses`, `applied_expansion_type`.
* *Operation:*
1. Parse active courses against APH Annexure-11 Core Branches list (e.g., Civil, Mechanical, Electrical, Chemical).


2. Assert $\text{Count}(\text{Active Core Courses}) \ge 3$.




* *Expected Result:* If active core courses $< 3$, evaluate `REJECT (EXPANSION_CORE_BRANCH_DEFICIENCY)`. The system blocks expansion applications unless 3 core branches are active.




* **RULE-EXP-02: Core Branch Intake Reduction Floor**
* *APH Source Provision:* Chapter II, Clause 2.6(g), 2.18(a), p. 16, 25.


* *Applicability:* Change / Reduction in Intake.
* *Inputs:* Application Record `course_name`, `previous_approved_intake`, `proposed_reduced_intake`.
* *Operation:*
1. If `course_name` is in Core Branches:
2. Check reduction magnitude: $(\text{previous\_intake} - \text{proposed\_intake}) \le 0.50 \times \text{previous\_intake}$.


3. Check absolute floor: $\text{proposed\_reduced\_intake} \ge 30$.




* *Expected Result:* Pass if reduction does not exceed 50% and retains at least 30 seats; else flag `FAIL (CORE_INTAKE_REDUCTION_BELOW_FLOOR)`.




* **RULE-EXP-03: Regulatory Clean Slate Enforcement**
* *APH Source Provision:* Chapter II, Clause 2.6(e), p. 16.


* *Applicability:* Expansion (New Programmes or Intake Increase).
* *Inputs:* Backend Institutional Database `pending_inquiries_flag`.
* *Operation:* Query central vigilance/regulatory flag: `inquiries_pending_by_central_or_state_agencies == true`.


* *Expected Result:* If `true`, output `BLOCK (EXPANSION_BARRED_DUE_TO_PENDING_INQUIRY)`.

### 8. Unresolved Questions & Implementation Boundaries

The following regulatory items contain ambiguities in the APH text that must not be hard-coded into the deterministic engine without explicit AICTE administrative confirmation:

1. **State-Specific Land Quantity Conversion vs. FSI/FAR:**
* *Ambiguity:* Annexure 3.1 states that land requirements are no longer expressed as fixed acreage (e.g., 5 acres rural vs. 2.5 acres urban) but are "based on prevailing FSI/FAR norms applicable for that location as declared by the respective competent authority".


* *Technical Boundary:* Because local municipal bye-laws vary across every state and urban local body, the platform cannot maintain a universal deterministic FAR calculation. It can only extract the FAR declared on the approved building plan and verify that the calculated built-up area does not exceed that declared ceiling.




2. **Provisional Occupancy Certificate Permissibility in Initial Approvals:**
* *Ambiguity:* Clause 6.17(g) and Annexure 1.1(iv) state that an applicant must produce an Occupancy Certificate or an Affidavit that it will be produced on completion. Conversely, Annexure 3.1(c) notes that "in case of partial/provisional Occupancy Certificate issued by the State Government authority, the same shall be considered only for 2 consecutive Academic Years".


* *Technical Boundary:* The system should flag any provisional certificate as `MANUAL_REVIEW_REQUIRED`, leaving acceptance of a provisional certificate during initial approval to the Scrutiny Committee.




3. **Faculty Reduction Rule for Low Enrolment vs. Fixed FSR:**
* *Ambiguity:* Annexure 5.3 states that "in case of the average admission during last 3 years is less than or equal to 50% of the average sanction intake, the requirement of faculty members shall be reduced by 25%". However, Chapter VII, Clause 7.4(c) prescribes penalties for any violation of the baseline Faculty:Student ratio.


* *Technical Boundary:* Low-enrolment faculty reductions should not be automatically applied during preliminary validation. When calculated faculty falls between 75% and 100% of standard FSR, the backend should flag the finding as `MANUAL_REVIEW_REQUIRED (ENROLMENT_DISCOUNT_APPLIED)` for human verification against historical admission records.




4. **External API Verification Limits:**
* *Boundary:* External verifications (such as Sub-Registrar land registration portals or State Fire Department databases) cannot be assumed to offer public APIs. When direct endpoints are missing, the platform must assign status `SOURCE_UNAVAILABLE` or `VERIFICATION_PENDING` and route the record to human scrutiny without marking the document invalid.
